Demod: System Architecture

Local-first Windows dictation app · Tauri v2 + whisper.cpp · v0.1.0

Rust Backend Modules

  • • main.rs: hotkey, overlay host, app lifecycle
  • • recorder.rs: state machine, Esc cancel, focus guard
  • • audio.rs: cpal WASAPI capture, WAV, RMS emit
  • • settings.rs: config.json load/save, serde
  • • pill_hittest.rs: WH_MOUSE_LL hook, drag, click-through
  • • sounds.rs: winmm start/stop pings
  • • history.rs + applog.rs: transcript + event logs
  • • autostart.rs: HKCU Run key management
  • • downloader.rs: streaming model download + progress

Local ASR Pipeline

  • • whisper.cpp bundled as Tauri sidecar
  • • whisper-server: HTTP server, persistent between recordings
  • • Models: small (466 MB) / medium (1.5 GB) / large-v3 (2.9 GB)
  • • Downloaded from archive.org (small/medium) or HuggingFace
  • • Audio captured → WAV → posted to localhost → transcript
  • • No network required after model download
  • • 300ms reveal budget: processing pill only if slow

Privacy & Data Flow

  • • All config + models → %APPDATA%\com.demod.app\
  • • Audio deleted immediately after each dictation
  • • Transcript history: local-only, optional, size-capped
  • • Cloud path: audio sent to Groq only, nothing else
  • • Zero telemetry, no account system
  • • API key stored in plaintext config.json (local only)
  • • Single-instance mutex prevents hotkey conflicts
